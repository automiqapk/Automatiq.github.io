# Automiq — Website institucional

Website estático da Automiq, desenvolvido com HTML, CSS e JavaScript sem dependências externas. Foi preparado para funcionar em computador, tablet e telemóvel e pode ser publicado diretamente no GitHub Pages.

Automiq

A Automiq é uma marca tecnológica fundada por Tomás Silva, dedicada à criação de soluções digitais simples, organizadas e adequadas a necessidades concretas.

O seu propósito é utilizar a tecnologia para melhorar processos, organizar informação e reduzir tarefas repetitivas. Cada projeto é desenvolvido com atenção ao contexto, à clareza e à facilidade de utilização.

A Automiq orienta o seu trabalho por três princípios:

Compreender antes de construir;
Simplificar antes de automatizar;
Comunicar com clareza e transparência.

A marca procura desenvolver soluções funcionais e responsáveis, evitando complexidade desnecessária e promessas exageradas.
